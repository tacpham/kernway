# kernway-cli — Developer CLI

## Purpose

`kernway` command: development workflow, build, project scaffolding.

## Commands

### `kernway dev`

```bash
kernway dev
# [kernway dev] Starting development server...
# [kernway dev] Watching src/ for changes...
# [kernway dev] App ready at http://localhost:8080
#
# (edit a file)
# [kernway dev] Change detected: src/controller/user_controller.rs
# [kernway dev] Building... (2.3s)
# [kernway dev] Hot-reloaded: 0 in-flight requests drained
# [kernway dev] App ready at http://localhost:8080

# Options:
kernway dev --port 3000
kernway dev --watch src/,templates/    # custom watch paths
kernway dev --no-reload                # disable hot reload (restart instead)
```

### `kernway build`

```bash
# Production binary
kernway build
# Output: target/release/my-app  (single static binary ~3-6MB)

# musl static binary for Docker scratch
kernway build --target x86_64-unknown-linux-musl

# Cross-compile
kernway build --target aarch64-unknown-linux-gnu
```

### `kernway new`

```bash
# Scaffold new project (like Spring Initializr)
kernway new my-app
# ? Template: [REST API / Web App / API + Templates]
# ? Database: [None / PostgreSQL / MySQL / SQLite]
# ? Add validation? [Y/n]
# ? Add observability? [Y/n]
#
# Created: my-app/
# ✓ Cargo.toml
# ✓ src/main.rs
# ✓ src/controller/
# ✓ src/service/
# ✓ src/repository/
# ✓ src/model/
# ✓ config/application.toml
# ✓ migrations/
# ✓ templates/       (if template selected)
# ✓ Dockerfile
# ✓ .github/workflows/ci.yml
```

### `kernway db`

```bash
kernway db migrate           # run pending migrations
kernway db migrate --dry-run # show SQL without running
kernway db rollback          # rollback last migration
kernway db status            # show migration status
kernway db new add_users     # create new migration file
```

### `kernway check`

```bash
# Validate project setup without running
kernway check
# ✓ Workspace structure valid
# ✓ kernway-abi version compatible
# ✓ All #[component] dependencies resolved
# ✓ No circular dependencies
# ✓ Route conflicts: none
# ✓ DATABASE_URL set
# ✓ Pending migrations: 0
```

## Installation

```bash
cargo install kernway-cli
```

## Dockerfile Generated by `kernway new`

```dockerfile
# Multi-stage build — minimal production image
FROM rust:1.76 AS builder
WORKDIR /app
COPY . .
RUN cargo install kernway-cli && kernway build --target x86_64-unknown-linux-musl

FROM scratch
COPY --from=builder /app/target/x86_64-unknown-linux-musl/release/my-app /app
EXPOSE 8080
CMD ["/app"]
# Final image size: ~5-10MB
```
